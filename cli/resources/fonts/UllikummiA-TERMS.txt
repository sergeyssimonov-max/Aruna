What the text says, and what it does not
----------------------------------------

and commercial distribution. Four uses are granted: academic purposes, research
purposes, scientific publications, and websites for scholarly purposes.

Distribution of the **unmodified** font for a non-commercial, scholarly purpose
is neither forbidden by the first list nor named in the second. The owner of
this repository decided on 2026-09-09 that this copy falls within the terms:
the use is academic and scholarly, the repository is non-commercial, the file
is unmodified, and the credit is carried. That is a reading of the terms
recorded with its date and its reasons — not a legal finding, and not a
permission anyone granted us in writing.

Provenance
----------

The upstream package is `Ullikummi.zip`, three faces (A, B, C) of which only
A is used here: neither B nor C covers a code point this corpus uses that A
does not.

    https://hethport.net/cuneifont/download/Ullikummi.zip
    https://smaw.de.dariah.eu/cuneifont/download/Ullikummi.zip   (DARIAH mirror)

`hethport.uni-wuerzburg.de`, the portal's other name, refuses the TLS handshake
from macOS 13 / LibreSSL 3.3.6. Both routes above served packages with the same
SHA-256.

    Ullikummi.zip     28f8bb7ebc572009760066373edbf730c5bbcc2e974ec85109a6a44e5a2e55c7
    UllikummiA.ttf    2ca4357d66d7cde6b0785be22f4c3ed3427289fdb0330eceabe89da24c4041cf

The copy in this directory has that SHA-256. `cli/tests/fonts.rs` holds it to
its MD5 and its length on every test run, because the terms forbid modification
and a modified file here would breach them silently.


Why this font is here at all
----------------------------

`U+100000` is a cuneiform sign with no Unicode code point. Vanséveren allocated
it in the Supplementary Private Use Area and documented it in the Hittite Sign
List that accompanies the fonts. It occurs 927 times across 913 lines in 370 of
the corpus's 23 936 documents, and no other face on a stock macOS machine draws
it — not Semiramis, not Noto, none of the 366 system faces.

For the PDF stage the font's `fsType` is `0x0008`, Editable Embedding, which
permits embedding *and* subsetting. A scholarly, non-commercial PDF that embeds
a subset of this face is within both that bit and the written terms above.
