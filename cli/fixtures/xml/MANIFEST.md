# XML fixtures

Every fixture here is **synthetic** — written for this repository, not taken
from the corpus. The corpus is 71 MiB, is not committed (see `.gitignore`),
and is not this project's to copy. Where a fixture reproduces something the
corpus really contains, the entry says how many documents that is and the
number comes from `cargo run --release --example corpus_inventory`.

Digests are **SHA-256**. Re-check them with:

```sh
cd cli && shasum -a 256 -c fixtures/xml/SHA256SUMS
```

`tests/xml_contract.rs` checks that this file and the directory list the same
fixtures, and that each is the size recorded here — enough to catch an
accidental edit without carrying a second digest implementation.

Three resource fixtures are **not** stored here and are generated by the test
that needs them, because they are large and their size is the whole point:
50 000 levels of nesting, 100 000 attributes, and an 8 MiB text node.

| column | meaning |
|---|---|
| purpose | why this fixture exists |
| features | what makes it structurally distinct |
| expected | what the current system must do with it |
| future PDF | what a converter will have to do with it |
