# Переход Aruna в Codex и версия 3.1.0

Дата проверки: 15.11.2026. Исходный `main`: `f8d874f3238c4fb503df13e586c8d68b1b40ff1a`.

## Состояние проекта

Aruna – локальное приложение Tauri 2 для корпуса TLHdig. Rust-ядро скачивает
и проверяет архив, сохраняет XML, строит PDF через Typst, опись и манифест;
Svelte-интерфейс вызывает то же ядро. Рабочая платформа остается macOS 13.7.8,
Apple Silicon; выпуск содержит arm64 и x86_64. Порог окна – Safari 16,
порог экспортируемой описи – Safari 13. Форматы корпуса и PDF не изменялись.

Правила разработки теперь находятся в [AGENTS.md](../AGENTS.md).
[CLAUDE.md](../CLAUDE.md) оставлен как указатель для совместимости.
Рабочий каталог определяется корнем checkout, а не старым абсолютным путем.
Обязательного недоступного плагина Claude для редактирования Svelte больше нет;
проверки типов, компонентов и настоящего WKWebView сохраняются.

Предоставленный [чат Claude](https://claude.ai/share/7d45bd25-aa40-458f-9558-c6c2a411f211)
удалось открыть в браузере после блокировки прямого HTTP-доступа и веб-чтения
проверкой Cloudflare. Из истории объемом около 5,8 млн символов прочитаны
начальные решения за 20–23 августа, последние поручения и обсуждения
26–29 октября, а также относящиеся к переходу описания проверок.
Скрытые в публичной версии вложения недоступны; их содержание не предполагается.

В просмотренной части подтверждены требования владельца: macOS 13 и Xcode 15.2,
закрепленный pnpm без `latest`, нативные E2E через WebdriverIO и tauri-service
вместо Playwright, возвращение cargo-llvm-cov и nextest в стек, единственный
логгер с `cfg(not(e2e))` и типизированный IPC через закрепленные tauri-specta
зависимости. Эти решения сверены с репозиторием; остальное основание перехода –
его содержимое, история Git и PR. Последние обсуждения подтвердили
отдельную миграцию ureq 3, сохранение содержательных строк публикаций PDF,
предел фазы PDF 145 с и необходимость независимого XML-эталона. Исторические
задания со сроками октября и номером 3.0.2 не подменяют текущее поручение
о 3.1.0 и Rust 1.100.0.

Проверены перечисленные в конце чата незавершенные пункты. Одинокая `.owner`
уже безопасно убирается после проверки блокировки и покрыта тестом.
`ino-check-03` описывал момент остановки измерительного сценария, а не
подтвержденный дефект приложения. Паника при неверном пути остается в
служебном `pdf_gate check`, не в пользовательском CLI или окне. Изменение
повторов сиглума и правил языка PDF требует отдельной содержательной приемки;
при переходе их отображение сохранено.

## Окружение и исправления

- Node **22.23.5** закреплен в `.node-version` и установлен на машине владельца.
  Официальный macOS arm64-архив проверен по SHA-256
  `e7131995759b61a0170b646010d2ad35a5d37b4cb0d471f3e8317eac6f742f3d`.
  Прежний Node 22.23.3 сохранен в `~/.local/opt` для отката.
  npm из официального комплекта сообщает **10.9.9**. В чате Claude описана
  прежняя ручная установка npm 12.0.2; это историческая запись, а не версия
  текущего официального комплекта. Для проекта используется только
  **pnpm 11.28.11**.
- Rust **1.100.0**, текущий stable на дату проверки, закреплен в
  `rust-toolchain.toml`; обе macOS-цели установлены. Xcode **15.2 (15C500b)**,
  SDK **14.2** и Rust edition 2021 сохраняются.
- В `0b856bf` ошибочно изменили тестовую строку `&lt;AOxml&gt;` на настоящий тег.
  Восстановлен исходный пример и добавлен отдельный тест настоящего тега в
  некорректном XML. Рабочий классификатор не менялся: контракт требует
  сохранять поврежденные документы корпуса и сообщать о них отдельно.
- Для Cargo 1.100 условный импорт обозначает намеренную зависимость
  `tauri-plugin-log` в E2E-сборке. Второй логгер не регистрируется.
- Сборка выпуска передает Cargo `--locked`, отвергает E2E и подмену
  конфигурации выпуска; штатные `--bundles app` и `--ci` поддерживаются.
  E2E-сборка также использует `--locked` и локальный закрепленный
  `@tauri-apps/cli` 2.12.4. Обнаруженный глобальный `cargo-tauri` 2.11.4
  больше не определяет версию инструмента для E2E. Сам глобальный бинарник
  не заменялся, чтобы не менять окружение других проектов.
- Исправлен сам PDF-заслон: неуспешный или неполный вывод PDFKit и пустой
  результат `xmllint --c14n` больше не засчитываются как успешная проверка.
  Добавлены девять регрессионных тестов. Код генерации PDF не менялся.
- Генератор лицензий теперь отказывает до записи файла при отсутствующем,
  пустом или не содержащем установленных locked-пакетов npm-store.
  Восемь subprocess-тестов проверяют отказы и сохранение прежнего файла.
  Текущий перечень соответствует установленным зависимостям: 1422 пакета,
  682 различных текста и 163 строки `requires review`; число текстов совпадает
  с 3.0.2. После согласованных patch-обновлений перечень пересоздан; изменились
  ссылки на версии двух Rust-пакетов, тексты лицензий прежние.
- CI теперь выполняет строгий pnpm-аудит. Проверка GitHub API подтвердила
  `approval_policy=all_external_contributors` для внешних PR; self-hosted
  runner `Mac-Studio-Vera` доступен. Настройки доступа не расширялись.

Исходные выпуски инструментов: [Node 22.23.5](https://nodejs.org/en/blog/release/v22.23.5),
[Rust 1.100.0](https://blog.rust-lang.org/2026/11/12/Rust-1.100.0/).
Обновления моложе семи дней применены по прямому поручению владельца.

## Изоляция окончательной приемки

Владелец отдельно подтвердил включение rustix 1.1.6 и async-executor 1.14.1
в 3.1.0. Обновления выполнены через Cargo, прямые зависимости не добавлялись.
Полные normal/build-графы обеих macOS-архитектур до и после совпали;
Windows-ребра, выбранные резолвером, описаны в обзоре зависимостей.

В исходном checkout параллельно менялся Cargo.lock: после этих двух пакетов
появились plist 1.10.3 и tao 0.37.2. Тест лицензий поймал изменение lock-файла
во время проверки; незаконченный прогон покрытия остановлен с сохранением
журнала. Чтобы не проверять меняющийся состав, окончательная работа перенесена
в отдельный managed worktree `aruna-310-final`, ветка
`codex/stabilize-3.1.0-final`. Изменения исходной папки сохранены.
Дополнительные plist/tao в этот выпуск не включены.

Проверенный состав зафиксирован коммитом
`87b09d7e2de0e403a64f78bfd80baf08415c4c5c`; он содержит только согласованные
изменения Cargo.lock и пересозданные notices поверх прежних коммитов перехода.
Контрольные суммы входных файлов проверены перед сборкой. Последующие правки
отчета не меняют собираемое приложение.

## Проверка версии 3.1.0

Фронтенд: **329 тестов в 20 файлах**, check/lint/format и production build
прошли. Покрытие: 83,99 % statements / 75,90 % branches / 64,70 % functions /

Обычный Rust-набор в изолированном checkout: **790 тестов**, 749 CLI и

`fuzz_naming`, `fuzz_pipeline`, `fuzz_layers`, `fuzz_xml`; все завершились
успешно. В XML-примере проверено 200 000 мутированных входов, в pipeline –
200 000 наборов, искажений нормализации, неверного JSON и HTML нет.
Гонка `runs_racing_for_the_lock_never_hold_it_two_at_once` прошла

Покрытие Rust обычным `pnpm coverage`, без тяжелого архива, проверенного
отдельно: ядро **96,00 / 97,26 / 96,22 %**, оболочка

Нативный WebdriverIO на macOS 13.7.8 прошел **6 из 6** сценариев с закрепленным

## Корпус и независимая приемка PDF

Контрольный пакет: **23 936 документов, 23 713 PDF, 223 ожидаемых отказа
модели, 47 654 файла**, шаблон `aruna-pdf-template 2`.
Сумма пакета: `a18ec28ea57cd9127b5b515c9f84cf8b7d1312107b8892005a03bc3790c049df`.

- `pdf_gate check --c14n --pdfkit`: все критерии выполнены, неизвестных имен
  нет, отрицательные контроли PDFKit и структурных проверок пойманы.
- Независимый исторический XML/Expat-эталон и Xpdf дали **23 695 совпадений**.
  Остальные **18 записей** совпали с прежними остаточными расхождениями
  ActualText, включая пути и содержание различий; новых расхождений нет.
  В тексте, Info, XMP и описи **нет утечек разметки**. Исходники этого эталона
  сверены по SHA-256 с отчетом приемки 3.0.2; текущая модель Aruna его не заменяет.
- Системный PDFKit независимо открыл **все 23 713 PDF / 36 500 страниц**.
  Проверены статус каждого процесса, полное соответствие строк и путей,
  положительное число страниц и отсутствие напечатанных букв меток `U+...`.
- Сравнение с сохранившимся пакетом 3.0.1 на шаблоне 2: из 23 940 файлов
  без PDF и манифеста отличается только HTML-опись: она стала на 42 байта
  меньше за счет комментариев сборщика (`//#region`/`//#endregion`). Данные и исполняемый JavaScript
  совпадают. Все XML побайтно прежние. Этот пакет не называется подлинным
  артефактом 3.0.2; независимый текстовый эталон 3.0.2 проверен отдельно.

Серии из пяти измерений PDF выполнялись во временных каталогах вне Documents,
чтобы собственные тестовые PDF не нагружали индексацию.
Команда инструмента – точно по разделу 6.8:
`cargo build --release --locked -p aruna --example pdf_gate`, нативный target,
без дополнительных RUSTFLAGS, MACOSX_DEPLOYMENT_TARGET и SDKROOT.

Первая полная серия: **141,7 / 141,3 / 141,4 / 142,3 / 142,7 с**,
медиана **141,7 с**, все пять пакетов одинаковы и совпадают с проверенным
пакетом выше. Перед запуском load1 1,55, CPU idle 89,11 %. Предел 145 с
соблюден, но превышен сигнальный порог 134 с, поэтому выполнен повтор.

Повтор: **141,5 / 142,9 / 193,3 / 203,3 / 155,3 с**, медиана **155,3 с**:

Одновременно появились отдельные незакоммиченные обновления Cargo.lock
